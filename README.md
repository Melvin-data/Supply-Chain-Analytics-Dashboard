# Supply Chain Analytics Dashboard

## Project Overview
This project analyzes supply chain operations data to identify logistics inefficiencies, shipping costs, supplier performance, and transportation trends.

The dashboard was built using Microsoft Excel to help stakeholders monitor operational performance and improve supply chain decision-making.

---

## Business Objective
The goal of this project was to provide visibility into:

- Shipping costs
- Supplier performance
- Product demand
- Transportation mode usage
- Regional sales distribution
- Operational efficiency metrics

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Metrics
- Data Cleaning
- Dashboard Design

---

## Dashboard Metrics

- Total Revenue
- Total Shipping Costs
- Average Defect Rate
- Total Products Sold

---

## Key Visualizations

### Revenue by Product Type
Tracks top-performing product categories.

### Shipping Costs by Carrier
Analyzes transportation costs across carriers.

### Orders by Location
Shows geographic demand distribution.

### Transportation Mode Breakdown
Tracks usage of transportation methods.

### Supplier Defect Rate
Identifies supplier quality issues.

---

## Key Insights

- Certain carriers generated significantly higher shipping costs.
- A small number of locations drove most product demand.
- Product sales were concentrated in specific categories.
- Supplier defect rates highlighted operational improvement opportunities.
